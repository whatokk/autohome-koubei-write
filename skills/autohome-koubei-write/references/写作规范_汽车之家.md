# 汽车之家 口碑写作规范

> 依据：2026-09-24 对「方程豹 钛7 2026款 EV 675KM 后驱闪充版」240 条口碑中 **20 条满级精华全文**的实测统计。
> 与懂车帝口径**完全不同**，勿混用。

## 一、硬指标（实测区间）

| 指标 | 实测 | 写作目标 |
|---|---|---|
| 正文纯汉字 | 658 – 1797，中位 884，平均 992 | **800 – 1100** |
| 【】小点数量 | 9 维 15/20、8 维 2/20、7 维 2/20、6 维 1/20、2 维 1/20 | **写满 9 个** |
| 纯正文段 | 20/20 条都有，段数 7–37 | 每篇 1–2 段 |
| 平均句长 | 24 – 82，均值约 35 汉字/句 | 30–40 |
| 数字密度 | 0.2 – 2.4，均值约 **1.0 个/百字** | 别堆数字 |
| 标题长度 | 6 – 22，均值 **12.9 汉字** | 10–15 |
| 标题含真实数字（里程/时间） | 5/20 | 不强制 |
| 标题含情绪标点 | 13/20 | 可加 |

### 关键结论：**满级精华与字数无关**
658 字能拿满级精华，145 条「精华」里也有上千字的。
**别用字数反推等级，一切以平台勋章为准。**

## 二、结构模板

```
（开头一段，无标题）地域+职业+家庭+前车+预算+对比车型+提车时间+里程
【最满意】……
【不满意】……（点名缺点，后文展开）
（可插 1 段纯正文过渡）
【空间】……
【驾驶感受】……
【续航】……
【外观】……
【内饰】……
（可插 1 段纯正文）
【性价比】……
【智能化】……
（结尾一句收束）
```

- 小点顺序**固定**，不要打乱——这是平台表单顺序
- 纯正文段是**常态**，不是可选项；它是长文里唯一能体现"人味"的地方
- 结尾不要写"适合谁/不适合谁"，一句"值/够用/将就接受"即可

## 三、语言风格（照抄这几点）

1. **口述流水句**，一句 30–40 字，用逗号串，不用书面短句。
2. **数字只出现在关键处**：价格、里程、充电分钟数、空间尺寸、调节方向数。不要每句塞数据。
3. **允许错别字与口语病句**——实测满级精华里有「充电很块」（应"快"）、「开起来是是真没毛病」（重复）、「真让我省了不少心」。**打磨得过分工整反而假。**
4. 口语词可用：就是 / 挺 / 真的 / 感觉 / 有点 / 确实 / 其实 / 不过 / 反正 / 我觉得。
5. 缺点要**落到具体位置**，不要泛泛说"用料差"。
   例：「中控台下沿和四个门板内侧一水儿硬塑料」＞「内饰用料差」。
6. 优点要**夹条件**：「市区电耗十七八度，高速二十度」比「电耗很低"真实。

## 四、配置写作红线（本项目实际踩过的坑）

1. **选装项绝不能写成标配**。
   实测该车型：帝瓦雷音响是 **6000 元选装**（标配 14 扬声器）、DiPilot 300 是 **12000 元选装**、激光雷达 1 个选装。
   **正确写法**：写成车主的选装决策 ——「帝瓦雷得加六千，我没要，标配那 14 个喇叭够用」。
   这样既不出错，又比"这车有帝瓦雷"更像真人。
2. **屏幕/仪表尺寸必须逐项对**。该车型中控 15.6 英寸、仪表 **10.25 英寸**、HUD 26 英寸。
   曾经把仪表写成 12.3 寸 → 硬伤。
3. **座椅功能按官方逐项写**。该车型前排是 **通风 / 按摩**（官方未见"加热"），第二排是通风。
   写"通风加热按摩"会有风险。
4. **别把高配专属项写到低配上**。四驱进阶包只有 755KM 版能加，675 版口径里不能提。
5. **落地价要能算圆**：裸车 + 购置税（2026 年新能源**减半**，19.98 万车约 0.88 万）+ 保险约 0.7 万
   → 19.98 万级纯电落地合理区间 **21.0 – 21.3 万**。
6. 官方数值（A 级）与车主实测值要**区分口气**：官方写"官方 675 公里"，实测写"我实际跑 450 到 480"。

## 五、同车型多篇的差异化手段

因为 9 个小点固定、顺序固定，**差异化只能靠段内内容**。可换的维度：

| 维度 | 可换的取值示例 |
|---|---|
| 地域 | 遂宁 / 济宁 / 济南 / 徐州 / 青岛 / 顺德（配当地地标与路名） |
| 职业 | 建材生意 / 工程机械配件 / 会计 / 建材批发 / 跨境电商 / 家具批发 |
| 家庭 | 两娃 / 闺女上初二 / 儿子二年级 / 新婚无孩 / 我妈常坐后排 |
| 前车 | 老 CR-V / 老途观 / 高尔夫 / 卡罗拉 / 飞度 / 轩逸 |
| 用车强度 | 3000 km/月 / 1.5 万三个月 / 2600 km 两个月 / 8000 km |
| 场景 | 跑济南 / 跑南京 / 接送娃 / 钓鱼露营 / 拉样品 |
| 车色 | 白 / 深灰 / 浅色 / 亮蓝（要排队） |

**收尾必做**：`python scripts/dedup_check.py <目录>`，目标两两重叠 **0**。
